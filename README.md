## Publishing

1. Create the repository `mfnce201` under `drhaas-eubs`.
2. Upload the *contents* of this folder to the repository root (`index.html` and `assets/` at the top level).
3. Settings → Pages → Deploy from a branch → `main` / `(root)`.
4. Live at `https://drhaas-eubs.github.io/mfnce201/`

The page `finance-glossary.html` (Finance Glossary, 120 entries) is linked in the top navigation of every page.

All links are relative; no build step on GitHub Pages.
